Reference-row policy: external checkpoint, training budget/epoch/realisation/selection unknown, no training bindings, provenance = the file digest and the authors' release; it is a checkpoint-performance reference, not an arm of the recipe comparison. Acceptance: |difference| ≤ 3 × the five-seed SD + 2 % of the historical value for each of EDT/C50/T60 — if met, the seen loading path is accepted; if not, the discrepancy is INVESTIGATED (a 200-query run of the authors' `eval_seen.py` and of `tools/exp07_eval.py` on the same manifest with the authors' random draw replaced by the manifest's references; budget ≤ 2 GPU-h) and no seen-arm evaluation is admitted until the cause is recorded. Implementation parity (deterministic, above) and this historical calibration are separate checks. The released row's epoch is recorded as unknown; its K = 1 row is an evaluation with one reference, not a separately trained K = 1 model.
- **Estimand (frozen)**: metrics EDT (s in the LaTeX table, ms in the canonical JSON; SD converted with the mean), C50 (dB), T60 (%), plus loss and log-STFT MSE in the JSON; per arm × K the table cell = mean ± sample SD (ddof 1) over the five seeds of each seed's mean over its finite queries (TABLE_V1 rule; a seed whose finite count differs from the others by > 2 refuses the cell); epoch-12 checkpoints only (no test-selected epoch). Descriptive pairs (`cyl − simple`, `aug − simple`, and `released − simple` labelled reference) at K = 8 and K = 1: per query the five-seed plain mean per arm on the paired cohort (finite for all five seeds in both arms; empty cohort refuses the cell; exclusions reported per arm/seed), statistic = absolute difference of means in native units AND the relative difference (Δ/mean_simple, %) — both recomputed inside each of 20 000 query-level bootstrap resamples (seed 0; two-sided 2.5/97.5 percentile, pointwise), with the existing whole-room cluster bootstrap (`paired_stats`: rooms resampled with replacement, every query of a drawn room retained, query-weighted statistic; retained rooms after masking reported) as the secondary interval around the same query-weighted statistic; both arms' means on each paired cohort are reported next to the table means (which use each arm's own finite set); quantiles are exact order statistics (2.5 / 97.5 % of 20 000); the two-seed (0/1) convergence diagnostic reports the maximum endpoint movement / interval width per cell with tolerance 0.10 — a cell above tolerance is flagged and its interval re-run at n_boot 40 000 before publication. **No verdict, no significance marker, no superiority/equivalence claim**; the intervals are checkpoint-conditional descriptive intervals (five evaluation seeds do not estimate training-seed variability) and permit statements about these checkpoints only, never causal or method-superiority claims; the released row's intervals are reported the same way.
