## Question
Does training-time yaw augmentation of the SimpleViT xRIR (per-sample active yaw of the whole receiver-centred scene, audio untouched; port of FLAC exp_17) keep k = 0 accuracy within +3 % of the same-budget control (H1, non-inferiority) and reduce the yaw-rotation degradation measured in exp_03 (H2, C50 primary at ±22.5°/±45°), with near-invariance of the augmented model itself (TOST ±2 % at the seven patch-aligned angles)?

## Statistics (pre-registered, plan §3; producers `tools/paired_compare.py` profiles `H1_K8`, `H1_K1`, `H2_K8`, `TOST_K8`; `tools/results_table.py` profile `TABLE_V1`)
Cell = mean ± sample SD over the five seeds; per query the five per-seed errors are averaged with plain means (any non-finite value excludes the query from that cell; exclusions reported by category, arm and seed). Bootstrap over queries (n_boot = 20 000, seed 0; room-cluster secondary over 17 rooms). **H1**: ρ_j = (mean_aug − mean_control)/mean_control recomputed inside each resample, j ∈ {EDT, C50}; passes iff the one-sided upper bound Q_0.975 (family 2) < +0.03; superiority iff the upper endpoint of [Q_0.0125, Q_0.9875] < 0; wording "non-inferior" / "non-inferior on EDT (C50) only" / "not shown"; same rule separately at K = 1. **H2**: D_k = r_k(aug) − r_k(control) on shared resamples at k ∈ {32, 64, 448, 480}, family 8, cell passes iff Q_0.99375 < 0; C50 primary ("supported" all four / "partially" / "not supported"), EDT supportive. **TOST**: r_k(aug) within ±2 % at k ∈ {32, 64, 128, 256, 384, 448, 480}, family 14, α = 0.05/14 per side; "equivalent" / "equivalence not established". **Convergence gate**: decision-carrying companion interval recomputed with bootstrap seed 1; max endpoint movement / seed-0 width ≤ 0.10, else no canonical artefact. Exact order-statistic quantiles with a strict boundary. Single-seed runs are diagnostics only.
